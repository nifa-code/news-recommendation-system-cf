# 新闻推荐系统（UserCF 协同过滤）
基于 SpringBoot + Vue + Python 实现的个性化新闻推荐系统，采用用户协同过滤算法实现推荐功能。

## 项目结构
- frontend：Vue 前端页面
- backend：SpringBoot 后端接口
- algorithm：Python 推荐算法模块（UserCF、Bias 偏置模型）

## 技术栈
- 后端：SpringBoot、MySQL、Redis、MyBatis
- 前端：Vue2/Vue3、Element UI
- 算法：Python、Pandas、协同过滤 UserCF

## 功能模块
1. 用户登录注册
2. 新闻浏览、收藏、点赞
3. 基于用户行为的个性化推荐
4. 后台新闻管理

# 基于协同过滤的个性化新闻推荐系统 - 项目整体展示

**项目概述**：前后端分离个性化新闻推荐系统，集成用户认证、新闻推荐、行为采集、个人中心等完整功能，基于改进的**用户**协同过滤算法实现新闻推荐。

**技术栈**：后端（SpringBoot + SpringSecurity + MySQL）、前端（React + MUI）、推荐算法（Python + 协同过滤 + 时间衰减）、前后端交互（RESTful API）

**核心成果**：支持个性化实时推荐、已读过滤、行为记录，解决冷启动、重复推荐等问题，提升用户体验。

## 一、项目整体架构

采用前后端分离架构，核心架构如下：

- 前端：负责页面展示、用户交互、请求发起，基于React + MUI实现响应式设计。

- 后端：负责用户认证、行为采集、数据存储、接口提供，基于SpringBoot实现高可用服务。

- 推荐算法：基于Python实现改进版用户协同过滤，实时拉取用户行为数据，实现个性化推荐，使用60% 协同过滤 + 30% 热门 + 10% 最新混合式推荐。

- 数据存储：MySQL存储用户信息、新闻数据、用户行为记录，支持高效查询与数据持久化。

## 二、核心功能模块与页面展示

系统包含6大核心页面，覆盖用户从注册、登录、新闻浏览、个人管理的全流程。

### 1. 用户认证模块（注册+登录页面）

**核心功能**：实现用户注册、登录、身份校验，保障系统安全性，支撑后续个性化功能。

- 注册页面：支持用户名、密码录入，表单校验（非空、密码一致性、用户名唯一），密码BCrypt加密存储，注册成功自动跳转登录页。

- 登录页面：支持账号密码登录，登录成功颁发Token并本地存储，维持全局登录状态；未登录用户无法访问首页、个人中心等核心页面，登录失效自动跳转登录页。

**技术亮点**：基于SpringSecurity实现身份认证，Token过期校验，密码加密存储，防止明文泄露。

### 2. 首页推荐页面（核心推荐模块）

**核心功能**：个性化新闻推荐，实时刷新，已读过滤，最新新闻优先展示，是系统核心交互页面。

- 推荐逻辑：采用“60%协同过滤+30%热门新闻+10%多样化补充”混合策略，结合时间衰减权重（24小时内新闻权重1.3，7天内1.15，30天以上0.7）。

- 页面展示：新闻封面图、标题、摘要、分类标签、发布时间、阅读量/点赞量/收藏量，点击新闻可进入详情页。

- 交互功能：下拉刷新可实时更新推荐列表，已读新闻自动过滤，避免重复推荐。

**技术亮点**：Python协同过滤算法实时训练，Java后端已读过滤，前端实时请求更新，实现“刷新即更新”的流畅体验。

### 3. 新闻详情页面

**核心功能**：新闻完整展示，用户交互，行为自动采集，是用户行为数据的核心来源。

- 内容展示：新闻标题、完整正文、多图展示、发布时间、来源链接，支持图片预览。

- 自动行为采集：进入页面自动记录“点击”行为，停留阅读记录“阅读”行为，数据同步至后端并传入推荐算法模型。

- 用户交互：支持点赞/取消点赞、收藏/取消收藏，实时显示当前用户的交互状态，交互行为同步更新推荐权重。

**技术亮点**：行为采集无感知，避免重复记录导致的数据库异常。

### 4. 个人资料页面

**核心功能**：用户信息展示、个人数据统计，提升用户归属感，支撑个性化推荐。

- 信息展示：用户ID、用户名、注册时间等基础信息。

- 数据统计：展示用户累计点赞数、收藏数、阅读新闻数，直观呈现用户行为偏好。

- 附加功能：支持退出登录，退出后清除本地Token，返回登录页面。

  
### 5. 浏览记录页面

**核心功能**：记录用户所有已读/已点击新闻，支持回溯浏览，同时为已读过滤提供数据支撑。

- 记录展示：按时间倒序展示新闻标题、封面图、阅读时间，清晰呈现用户浏览轨迹。

- 交互功能：点击记录可重新进入对应新闻详情页，支持删除单条/批量删除浏览记录（可选扩展）。

**技术亮点**：与推荐系统联动，浏览记录实时同步至已读列表，确保推荐时不重复展示。

### 6. 收藏记录页面

**核心功能**：展示用户收藏的新闻，支持快速访问和取消收藏，强化用户偏好采集。

- 记录展示：按收藏时间倒序展示新闻标题、封面图、收藏时间，方便用户快速查找。

- 交互功能：支持取消收藏，取消后实时更新收藏状态和统计数据，同时调整推荐算法中的用户偏好权重。

  
## 三、核心技术与亮点

1. **个性化推荐算法**：基于Python实现改进版用户协同过滤，支持实时行为采集、时间衰减权重、混合推荐策略，解决冷启动（新用户推荐热门新闻）、重复推荐问题。

2. **用户行为采集与处理**：后端实现点击、阅读、点赞、收藏等行为的采集与防重复处理，解决React严格模式重复请求导致的数据库异常。

3. **已读过滤机制**：后端查询用户已读新闻ID，在推荐时自动过滤，提升用户体验，避免无效推荐。

4. **前后端分离架构**：React + SpringBoot实现前后端解耦，接口标准化，支持后续扩展与维护。

5. **完整用户体系**：基于SpringSecurity实现用户认证、权限控制，保障系统安全性与用户数据隐私。

## 四、项目价值与成果

- 功能完整性：覆盖用户注册登录、新闻推荐、详情浏览、个人管理等全流程，可直接部署使用。

- 技术落地性：提到的功能实现落地，能解决实际推荐场景中的三大问题（重复推荐、冷启动、实时更新）。

- 用户体验：已读过滤、时间衰减、实时刷新等功能，大幅提升用户浏览体验与推荐精准度。

- 可扩展性：架构设计合理，支持后续新增新闻分类、搜索、评论等功能，适配更多场景。

## 五、项目总结

本项目是一套完整的个性化新闻推荐系统，整合了用户认证、新闻展示、行为采集、个性化推荐、个人中心等核心模块，技术栈主流、功能完善、落地性强。通过改进版协同过滤算法与实时行为处理，实现了针对用户的个性化新闻推荐。
